# Точка по продаже донера (Абакан, 24/7)

## Как загрузить на GitHub Pages, чтобы отображались все фото:
1. Распакуйте архив. Внутри лежат файл `index.html` и папка `images` (в ней 7 файлов `.jpg`).
2. Зайдите в свой репозиторий на GitHub (`doner-abakan19`), удалите старый `index.html` (или просто загрузите новые файлы поверх).
3. Нажмите **Добавить файл -> Загрузить файлы** (Add file -> Upload files).
4. Перетащите в окно браузера сразу и файл `index.html`, и папку `images` целиком.
5. Нажмите зеленую кнопку **Commit changes**.
6. Через 1-2 минуты обновите ссылку `https://jonaba19.github.io/doner-abakan19/` на телефоне — все 7 фотографий будут загружаться прямо с вашего GitHub без блокировок.

## Как заменить картинки на свои реальные фото:
Просто замените файлы внутри папки `images/` на свои фотографии с такими же названиями:
- `hero.jpg` — главное фото в шапке
- `classic.jpg` — классический донер
- `grill.jpg` — фирменный донер на углях
- `cheese.jpg` — сырный донер
- `spicy.jpg` — острый донер
- `plate.jpg` — донер на тарелке
- `combo.jpg` — комбо-набор
