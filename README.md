# Лендинг «Точка по продаже донера» (Версия 3 с реалистичными фото)

## Что обновлено
- В главный экран и во все 6 карточек меню встроены реалистичные студийные фотографии сочного донера, мяса на гриле, картофеля фри и комбо-наборов.
- Сайт собран в один автономный файл `index.html` — не нужно отдельно загружать папки с картинками на хостинг.

## Как заменить фото на свои
Откройте `index.html` и вставьте прямые ссылки на ваши реальные фотографии в поле `img: "..."` внутри блока `const products` (или замените ссылку в теге `<img>` главного экрана).

## Публикация на GitHub Pages
1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите в корень репозитория файл `index.html`.
3. Перейдите в **Settings -> Pages**, выберите ветку `main` и нажмите **Save**.
